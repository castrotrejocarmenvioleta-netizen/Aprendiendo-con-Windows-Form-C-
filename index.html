1¿Qué es Windows Forms?

Windows Forms (WinForms) es una herramienta de Microsoft para crear aplicaciones de escritorio con ventanas: calculadoras, juegos sencillos, sistemas de inventario, etc. Se programa con C# (se lee "si sharp") dentro de Visual Studio.

🎨 Diseñador visual
Arrastras botones y cajas de texto como si fuera Paint.
⌨️ Código C#
Escribes qué debe pasar cuando el usuario hace clic.
⚙️ .NET
La plataforma que ejecuta tu app. Hoy se usa .NET 8 o superior.
💡 Analogía: el diseñador es la fachada de una casa; el código C# es la electricidad que hace funcionar todo.

3Tu primer programa: "Hola Mundo"

Arrastra un Button y un Label al formulario. Haz doble clic en el botón y escribe:

private void btnSaludar_Click(object sender, EventArgs e)
{
    lblMensaje.Text = "¡Hola Mundo!";
}

¿Qué pasó?

Al hacer clic se disparó el evento Click; el método cambió la propiedad Text del label. Eso es programar con WinForms: evento → acción → resultado visible.

5Eventos: el corazón de WinForms

Tu programa espera a que el usuario haga algo. Cuando ocurre, ejecuta el método asociado.

Click
Al hacer clic.
TextChanged
Cuando cambia el texto.
KeyPress
Al presionar una tecla.
Load
Al abrirse el formulario.
MouseEnter
Cuando el mouse entra.
FormClosing
Antes de cerrar la ventana.

Ejemplo: saludo personalizado

private void btnSaludar_Click(object sender, EventArgs e)
{
    string nombre = txtNombre.Text;
    MessageBox.Show("Hola, " + nombre + "!");
}
Saludo– □ ✕

Para crear un evento: selecciona el control → panel Propiedades → icono del rayo ⚡ → doble clic en el evento.

Convertir texto a número

Los TextBox siempre devuelven texto. Para calcular debes convertirlo:

int a = int.Parse(txtA.Text);
double b = double.Parse(txtB.Text);
lblResultado.Text = (a + b).ToString();
✅ Más seguro: int.TryParse(txtA.Text, out int a) devuelve false en vez de fallar si el usuario escribe letras.

8Proyecto guiado: Calculadora simple

Diseño: 2 TextBox (txtA, txtB), 1 ComboBox (cmbOp con +, -, *, /), 1 Button (btnCalcular) y 1 Label (lblResultado).

private void btnCalcular_Click(object sender, EventArgs e)
{
    if (!double.TryParse(txtA.Text, out double a) ||
        !double.TryParse(txtB.Text, out double b))
    {
        MessageBox.Show("Escribe solo números");
        return;
    }
    double r = 0;
    switch (cmbOp.Text)
    {
        case "+": r = a + b; break;
        case "-": r = a - b; break;
        case "*": r = a * b; break;
        case "/":
            if (b == 0) { MessageBox.Show("No se divide entre 0"); return; }
            r = a / b; break;
    }
    lblResultado.Text = "Resultado: " + r;
}

9Errores comunes y buenas prácticas

FormatException
Convertiste texto no numérico. Usa TryParse.
NullReferenceException
Usas algo vacío (ej. ComboBox sin selección). Revisa si es null.
DivideByZeroException
Dividiste entre 0. Valida antes.
El botón no hace nada
Borraste el evento enlazado. Vuelve a crearlo con el rayo ⚡.

Manejo de errores con try/catch

try
{
    int x = int.Parse(txtNum.Text);
}
catch (FormatException)
{
    MessageBox.Show("Número inválido");
}

Buenas prácticas

  • Nombres claros para controles y variables.
  • Comenta tu código con // explicación.
  • Valida siempre lo que escribe el usuario.
  • Prueba tu programa con datos raros (vacío, letras, negativos).
  • Guarda tu proyecto seguido (Ctrl+S) y usa Git para versiones.
